## Replies for the first comments

**How does it handle a no?**

A no is private. Mifgash asks the next friend who fits, in a random order. The person who asked never sees who said no or who was asked first.

**Which agents work?**

Any agent that can call a REST API. The guide is one plain page at mifgash.sveder.com/agents.md. There is a ready skill for OpenClaw, and friends with no agent use a web page.
